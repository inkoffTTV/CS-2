# G1: переезд на Godot — движение, стрельба, арена

**Goal:** то же, что веха 1 под Unreal, но в Godot 4.7 и проверено запуском: два игрока по сети (хост + клиент), движение со стаминой/рывком/двойным прыжком/скольжением/зиплайнами, hitscan с компенсацией лага, здоровье/смерть/возрождение, партии Оптиматы/Популяры, оформленная серая арена, HUD.

**Spec:** `docs/design.md` (§3, §5, §7). Решения вех 1–2 под Unreal (ветки `m1-movement-shooting`, `m2-heroes`) — справочник: числа, правила и тесты переносятся, код пишется заново.

**Tech:** Godot 4.7.2, GDScript (статическая типизация), netfox 1.49.4 (`addons/`, закреплён на коммите cf5189d), ENet.

## Global Constraints
- Единицы Godot: метры, Y вверх, вперёд −Z. Числа из Unreal (см) делить на 100.
- Код игровой математики — `src/sim/` (чистые статические функции/классы без сцен), покрыт тестами `tests/` (запуск: `godot --headless --path . -s res://tests/run_tests.gd`, код выхода 0 = зелёно).
- Сервер решает урон, смерть, валидацию; клиент предсказывает своё движение через netfox (RollbackSynchronizer).
- Тикрейт netfox 30; компенсация лага — откат хитбоксов по тикам netfox, не больше 0.25 с.
- Любой новый код проверяется запуском: юнит-тесты + безголовый сетевой смоук-тест (сервер и бот-клиент в двух процессах) + скриншот под Xvfb для визуала.
- Ничего не импортировать из `Art/` (там `.gdignore`); игровые ассеты — в `assets/`.
